# API Reference

Michelangelo AI exposes two reference surfaces, depending on how you're integrating.

## [Python SDK Reference](python-sdk/index.md)

Auto-generated reference for the `michelangelo` Python package — task and workflow decorators, compute-backend plugins, trainer utilities, and workflow variable types. Start here if you're authoring pipelines with the Python SDK.

## [gRPC Service Reference](grpc/conventions.md)

Full RPC and field reference for all 15 resource services that back the Michelangelo AI control plane — models, pipelines, serving, and jobs. Start here if you're calling the API directly over gRPC.
